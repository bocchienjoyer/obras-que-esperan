# Conversaciones con usuarios

Mostrar el mismo ejercicio a tres personas que investiguen asuntos públicos: localizar una obra, identificar a quién consultar y encontrar un documento. Registrar el rol y la fecha, sin publicar datos de contacto.

- ¿Cuándo buscaste por última vez información de una obra pública? ¿Qué necesitabas comprobar?
- ¿Dónde buscaste y cuánto demoraste? ¿Qué documento o dato costó más encontrar?
- Prueba el buscador con un lugar que conozcas. ¿Qué esperabas encontrar y qué pudiste verificar?
- ¿Qué usarías del CSV, la ficha o el pedido? ¿Qué información necesitarías antes de citar el registro?

Guardar una nota por conversación con el caso relatado, el tiempo reportado, la dificultad observada y una mejora propuesta.
